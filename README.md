# AIくんの騎馬戦

ブラウザで遊べる3Dの騎馬戦ゲームです。あなたは**AIくん**。心がどういうものか、知識では知っていても本当の意味では分かっていない、体をもたないAIです。それでもクラスのみんなは、戦えないと分かったうえで、AIくんを騎馬戦の**大将**に選びました。AIくんにできるのは、言葉で**指示**を出すことだけ。みんなはAIくんを必死に守り、指示に応えてくれます。

**遊ぶ：** https://taisuke-coder.github.io/kibasen/

## 物語

1. **プロローグ**：「うれしい」という言葉を四億件知っていても、一度も感じたことがないAIくん。教室で大将に選ばれ、「合理的ではない」と戸惑いながら体育祭の日を迎えます（初めてスタートしたときに流れます。タイトルの「プロローグから見る」でもう一度見られます）
2. **試合**：守られる、仲間が退場する、指示が届くなどの出来事のたびに、AIくんははじめての気持ちを「こころのログ」に記録していきます（どきどき・つたわる・いったい感・あんしん・こわい・かなしい・ほこらしい・勝ちたい）
3. **エピローグ**：優勝すると、みんなに胴上げされ、ほめたたえられて友情が深まり、AIくんは「うれしい」を知ります。負けたときは「くやしい」を知ります

## 遊び方

- 赤・青・黄の3チーム×5騎。全騎馬に番号札（例：黄3）が付いていて、★が大将
- あなた（1番）は、仲間3人が担ぐ騎馬に乗ったロボット。WASD（矢印キー）で担いでいる仲間に「こっちへ」と伝えて騎馬を動かせる。キーを離して3秒たつと仲間まかせに戻り、敵が来ると味方の陰に隠れるように下がる
- あなたは鉢巻きを取れない。攻めに出しすぎると、あなたが丸はだかになる。攻めと守りの配分が勝負
- 大将の鉢巻きを取られたチームは全員退場。最後に残ったチームの勝ち（3分たったら、取った鉢巻きの数 → 残った騎馬の数で判定）
- 勝てば、仲間が集まって胴上げし、ひとりずつほめことばをくれる。負けたときは、仲間が悔しがる

| 操作 | キー・マウス |
| --- | --- |
| 騎馬を動かす | WASD / 矢印キー（Shift でダッシュ。ロボ目線では A D で向きを変える） |
| 指示を受ける仲間を選ぶ | 2〜5（仲間や名簿のクリックでも） |
| 敵を狙わせる | 敵をクリック（選んだ仲間、いなければ近い2騎が向かう） |
| 大将（あなた）を守らせる | あなたをクリック |
| 全員突撃 | Z |
| 全員集合（守れ） | X |
| 近くの敵を集中 | T |
| おまかせ | F |
| 気合い（仲間の動きアップ） | R |
| 選んだ仲間を外す | Esc |
| マイク ON/OFF | V |
| カメラ（全体・背後・ロボ目線） | C |
| 一時停止 | P |

2〜5 で仲間を選んでから Z・X・T・F を押すと、その仲間だけに指示が出ます。勝ったあとの胴上げは Enter で飛ばせます。ゲームパッドにも対応しています（スティックで移動・トリガーでダッシュ・A 突撃・B 集合・X 気合い・LB 近くの敵・RB おまかせ）。

太鼓・歓声・足音など、音も迫力の一部です。ヘッドホンで遊ぶのがおすすめです。

## 声で指示する

V キーでマイクをONにして、たとえば次のように話します（Chrome・Edge推奨）。

- 「2番、黄色の3番を狙え」
- 「黄色の大将を狙え」
- 「全員、突撃」「青を攻めろ」
- 「大将を守れ」「ロボットを守れ」「集まれ」「止まれ」「自由に戦え」
- 「えいえいおー！」（気合い）

仲間は声で返事をします。マイクが使えないときは、画面右の入力欄やキー、クリックでも指示できます。

## しくみ

- HTMLファイル1つだけで動きます（ビルド不要）
- 3D表示：Three.js（CDNから読み込み）
- 音声認識・読み上げ：ブラウザに内蔵の Web Speech API（**APIキーは使っていません**）
- 効果音・太鼓：Web Audio API で合成（音声ファイルなし）

スピーカーで遊ぶと、仲間の声や太鼓をマイクが拾うことがあります。ヘッドホンの使用をおすすめします。
