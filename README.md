# 騎馬戦 3チーム大将戦

ブラウザで遊べる3Dの騎馬戦ゲームです。あなたは大将（1番）。自分の騎馬を操りながら、仲間の4騎には**声で**指示を出して、ほかの2チームの大将の鉢巻きを奪います。

**遊ぶ：** https://taisuke-coder.github.io/kibasen/

## 遊び方

- 赤・青・黄の3チーム×5騎。全騎馬に番号札（例：黄3）が付いていて、★が大将
- 大将の鉢巻きを取られたチームは全員退場。最後に残ったチームの勝ち（3分で判定）
- 相手の背中・横から取りにいくほど成功しやすい

| 操作 | キー |
| --- | --- |
| 前進・後退（一人称） | W S（↑↓ でも可） |
| 向きを変える（一人称） | A D（←→ でも可） |
| 鉢巻きを取る | Space |
| ダッシュ | Shift |
| 組み合う相手を切替 | Q |
| 気合い（仲間の動きアップ） | R |
| マイク ON/OFF | V |
| カメラ（一人称・背後・全体） | C |
| 一時停止 | P |

試合は騎手の目線（一人称）で始まります。敵に近づくと自動で「組み合い」になり、A・D（←→）で相手のまわりを回り込めます。背後・全体の視点では、WASD（↑↓←→）で押した方向に進みます。矢印キーのないPCでも WASD だけで遊べます。ゲームパッドにも対応しています。

太鼓・歓声・足音・心臓の音など、音も迫力の一部です。ヘッドホンで遊ぶのがおすすめです。

## 声で指示する

V キーでマイクをONにして、たとえば次のように話します（Chrome・Edge推奨）。

- 「2番、黄色の3番を狙え」
- 「黄色の大将を狙え」
- 「全員、突撃」「青を攻めろ」
- 「大将を守れ」「集まれ」「止まれ」「自由に戦え」
- 「えいえいおー！」（気合い）

仲間は声で返事をします。マイクが使えないときは、画面右の入力欄やキー（Z 全員突撃／X 全員集合／T 近くの敵を集中／F おまかせ）でも指示できます。

## しくみ

- HTMLファイル1つだけで動きます（ビルド不要）
- 3D表示：Three.js（CDNから読み込み）
- 音声認識・読み上げ：ブラウザに内蔵の Web Speech API（**APIキーは使っていません**）
- 効果音・太鼓：Web Audio API で合成（音声ファイルなし）

スピーカーで遊ぶと、仲間の声や太鼓をマイクが拾うことがあります。ヘッドホンの使用をおすすめします。
